## 확인하는 법

- 화면을 바꿨으면 브라우저에서 실제로 연다. 좁은 화면(375px)과 어두운 테마(운영체제 설정을 따른다)도 본다.
- 브라우저를 다룰 도구가 없으면 로드맵의 그 항목에 "브라우저 확인 못 함"이라고 적는다. 확인한 것처럼 쓰지 않는다.
- 브라우저 자동화 시험 도구를 개발 의존성으로 더해도 된다(4번, 8번). `npm run check` 가 2분 안에 끝나야 한다.
  4번에서 `playwright-core` 를 더했다. 브라우저 시험은 `tests/browser/` 에 두고 빌드 뒤에 돌린다
  (`npm run test:browser`, `docs/architecture.md` 의 "브라우저 시험"). 이 컴퓨터의 Chrome 을 쓰고, 없으면 실패한다.
