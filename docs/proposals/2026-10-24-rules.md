## CLAUDE.md

**바꾼다** — "지금은 1층이다. 서버가 없다." 문단을 아래로:

> **서버가 있는 공개 분석 서비스다(방향 B, `docs/direction.md`).** 서버 기능(route handler, DB, GitHub API 호출, 실행기
> 콜백)은 그 문서의 구조 안에서만 넣는다. 분석 도구·광고·외부 글꼴·외부 스크립트는 넣지 않는다. 비밀값(토큰, API 키)은
> 서버 환경 변수와 Actions secret 에만 두고 저장소·로그·화면에 남기지 않는다. 브라우저 저장소는 여전히 쓰지 않는다.

**바꾼다** — "사람만 하는 일" 의 "실제 남의 저장소를 검사해 결과를 보여 주기" 를 지우고 이렇게 적는다:

> 배포, 계정·저장소·도메인 만들기, 비밀값 만들기, 원격에 올리기(push), 라이선스 정하기, 비용 상한 정하기.
> 실제 공개 저장소의 분석은 서비스가 사용자의 요청으로 한다. 에이전트가 발표용 저장소를 스스로 골라 분석하지 않는다.

**바꾼다** — "명령" 의 `npm run check` 설명을 "lint + typecheck + test + build + 브라우저 시험" 으로(이미 그렇게 돈다).

**그대로 둔다** — `../Plitsoft-SDP` 는 읽기만(실행기는 CLI 를 고정 커밋으로 설치만 한다), CLI 출력에 없는 정보를 꾸며
내지 않는다, 법에 관한 사실을 지어내지 않는다, 표기 원칙.

## docs/commitments.md

- 1장 "CLI 가 이미 약속한 것" 의 "판정자를 켜면 코드가 밖으로 나간다는 것을 알린다" → 서비스는 판정자를 늘 켜므로
  "판정자를 켜 보라고 권하는 자리"가 없다. 서비스 쪽에는 이 줄을 적용하지 않는다고 적는다. `/view`(파일 열기)의 결과에는
  그대로 둔다. (오너 결정: 화면에 AI 사용을 따로 알리지 않는다.)
- 1장 "예시 결과에는 합성 예시라고 밝힌다. 실제 남의 저장소 결과를 예시로 쓰지 않는다" → "예시"는 그대로 합성만 쓰고,
  공개 저장소의 분석 결과는 예시가 아니라 사용자가 요청한 실제 결과로 보인다(저장소·커밋·분석 시각을 함께).
- 2장 "1층" → "/view 와 조문 도감은 지금 약속 그대로(연 파일은 브라우저 안에서만)" 로 줄인다.
- 2장 "2층" 을 방향 B 로 바꾼다:
  - 결과는 누구나 본다(오너 결정). 로그인 없이 요청한다(오너 결정). 남용·비용 상한을 둔다.
  - 서버에서 AI 판정자를 돌린다(오너 결정). 분석 대상 코드는 Anthropic API 로 나간다.
  - 검사는 GitHub Actions 의 새 VM 에서 하고 대상 코드를 실행하지 않는다.
  - 저장하는 것: 저장소·커밋·분석 id·진행 단계·시각·CLI 결과 JSON. 받은 압축 파일과 코드 전체는 저장하지 않는다.
    (CLI JSON 에는 AI 가 인용한 줄이 들어 있을 수 있다. 공개 저장소의 줄이다.)
  - 화면의 코드 줄은 GitHub 커밋 고정 링크로 보낸다.
- 4장의 "공개 저장소의 코드 줄을 브라우저가 GitHub 에서 직접 받는 것" 은 링크로 보내는 것으로 정리한다.
