# CLI 에 보내는 요청

웹이 CLI(`../Plitsoft-SDP`) 출력에 바라는 것이다. 웹은 CLI 를 고치지 않는다. 이 문서를 CLI 개발 쪽에 전달하는 것은
사람의 일이다. 상태는 2026-10-06, CLI 커밋 `8ae72d8`(0.3.0.dev0) 기준이다.

요청마다 "지금 어떻게 되어 있는지"는 `contract/cli-current/` 의 실제 출력에서 확인한 것이다.

## 동결 전에 필요한 것

AI 가 적용되지 않는다고 답해 뺀 단위를 그 수에 넣는지도 밝히기 | 정적 조건으로 충족된 단위는 `run.units` 개수에만 들어가고 어디에도 나오지 않는다. `kids-signup.fixed` 는 `units: 1`, `findings: []`. AI 가 푼 단위만 `run.ai_cleared` 에 나온다. ## 새 요청을 적는 법

일하다가 CLI 출력에 없는 것이 필요해지면 화면에서 꾸며 내지 말고 여기에 적는다.

- 무엇이 필요한지, 어느 화면에서 왜 필요한지
- 지금 출력에서 확인한 사실 (`contract/cli-current/` 의 어느 파일, 어느 필드)
- 없을 때 웹이 어떻게 보이는지
